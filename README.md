# 💖 Will You Be Mine? – Eine kleine interaktive Liebeserklärung

Eine süße, humorvolle Webanwendung, die ein Lächeln auf jedes Gesicht zaubert!  
Klicke auf „Nein“ und sieh zu, wie der „Ja“-Button bei jedem Versuch größer wird – eine charmante, digitale Art, „Ich hab dich lieb“ zu sagen. Wenn du „Ja“ wählst, erwartet dich eine süße Überraschung mit animierten Herzchen.  
Perfekt für eine digitale Valentinskarte oder als kreative Liebesbotschaft – verspielt, witzig und absolut unvergesslich!
