# 💖 Will You Be Mine? – Eine kleine interaktive Liebeserklärung

**Ein humorvolles und herzerwärmendes Mini-Webprojekt mit einer verspielten Überraschung.**

Diese Anwendung bringt ein Lächeln auf jedes Gesicht: Wer auf „Nein“ klickt, wird schnell merken – der „Ja“-Button wächst mit jedem Versuch. Eine süße, digitale Art „Ich hab dich lieb“ zu sagen – mit einem Augenzwinkern.

## Screenshot
![beMyValentine.png](https://github.com/MsCodingLabs/beMyValentine/blob/main/beMyValentine.png)


## ✨ Features

- 💌 Interaktive Frage „Will you be mine?“
- 😄 Witzige Reaktion bei Klick auf „Nein“ – der „Ja“-Button wird immer größer
- 💕 Animierte Herzchen auf der Folgeseite als süße Überraschung
- 🌟 Ideal als digitale Valentinskarte oder persönliche Liebesbotschaft

## 💡 Idee

Ein Projekt, das zeigt: Liebe kann verspielt, kreativ und digital sein. Perfekt, um jemanden auf charmante Weise zu überraschen – egal ob zum Valentinstag oder einfach zwischendurch.

## 🛠️ Technologien

- **HTML**
- **CSS** (inkl. Animationen & Transitions)
- **JavaScript**

## 📁 So funktioniert’s

1. Öffne `index.html` in deinem Browser.
2. Klick auf „Ja“ oder „Nein“… aber sei gewarnt 😉
3. Lass dich von den Herzchen verzaubern 💘
